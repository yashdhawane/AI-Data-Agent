# Fonts Directory

This directory should contain the GeistPixel-Circle.woff2 font file as a fallback for the BubbledotICG-FinePos font.

The BubbledotICG-FinePos font is loaded from OnlineWebFonts CDN as the primary display font.
Geist Pixel Circle serves as a local fallback if the CDN font fails to load.

Note: The current implementation uses the CDN font primarily, so this directory is provided for completeness based on the reference design.
